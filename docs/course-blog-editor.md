# 课程博客式编辑

2026-11-03更新课程管理页面，课程数据仍使用原有新增和修改接口。

## 使用

1. 管理员进入“课程管理”，点击“编辑”或“新增课程”。
2. 在完整写作页填写标题、分类与简介。分类使用下拉选择，子分类显示父级路径。
3. “写正文”模式可使用大标题、小标题、加粗、斜体、下划线、编号/项目列表、引用、链接、图片与撤销/重做。图片按钮通过原有上传接口存储文件；支持10MB以内PNG、JPG、WebP、GIF，也支持粘贴剪贴板图片文件。
4. “预览”检查排版；已有HTML课程可切换“HTML”修改。编辑器输出经DOMPurify清洗，移除脚本、事件属性和iframe等嵌入内容，视频通过独立的视频地址/文件字段维护。
5. 正文下方设置时长、积分、适用地区、封面与视频。图片上传时保存按钮禁用；保存时显示进行状态。页面内“返回”按钮对未保存修改显示确认提示，不代表浏览器关闭或手机物理返回已实现草稿恢复。
6. 点击“保存课程”。这会更新原课程，未新增自动发布、定时发布或本地草稿功能。

已有普通课程HTML在未改正文时保留原排版内容并执行安全清洗；富文本模式编辑后由Quill生成语义HTML。未承诺保留Quill不支持的任意复杂HTML布局。独立图解课程的共享教学步骤不由此正文编辑器改写。
