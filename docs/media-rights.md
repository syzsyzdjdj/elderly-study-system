# 素材来源与公开范围

核验日期：2026-11-03。维护者确认：当前没有课程图片与试听音频的自制记录或转载授权。因此，本次公开准备不把现有媒体标为“已授权”，不把站外可访问等同于可转载。

## 本次处理

- 原文件保留在本地，未删除、覆盖或重新标注版权。
- `.gitignore` 忽略课程媒体目录及原生 Android 位图；新仓库 `git add` 默认不纳入这些文件。已有仓库的跟踪文件不受此设置自动影响，须先审查索引。
- `tools/prepare_public_release.py` 只打包源码清单，默认排除所有待核验图片、图标、启动图、音频、视频及运行上传文件。
- `docs/media-inventory.json` 逐文件记录路径、SHA-256、字节数、来源证据状态和公开策略，可用来核验之后补充的授权是否对应同一个文件。
- `docs/screenshots/` 不再整体视为可公开。仅 `docs/public-media.json` 列出的8张已检查演示截图可进入源码包，并逐文件核对 SHA-256；图片变化后需重新审核。包含第三方教程缩略图的课程截图、运维终端截图及视频默认不分发，本地原文件保留。

2026-11-03 后续调整：`CourseStepGuide.vue` 不再绘制模拟手机界面，课程 3、4、15 改为逐步展示官方教程界面图，支持点击放大与双指缩放。来源、核对日期、版本与地区范围见课程图注及 `course-screenshot-sources.json`。这批图片保持原图，存放于 `frontend/public/tutorials/official/`；官方公开可访问不等于独立再分发授权，仍沿用媒体目录的公开包排除策略。公开源码缺少图片时，组件显示文字与原站来源入口，不恢复模拟图。

旧课程封面缺失时使用组件的缺图状态。Android 当前维护的 `android-app` 使用代码绘制的 drawable 图标；CI 同时检查 Web、Java 与 Android。旧 Capacitor 工程中的位图仍沿用排除策略。

## 重新纳入素材的要求

2026-11-04 正文配图修复：`frontend/src/utils/courseIllustrations.mjs` 保存本次新绘制的8张 SVG 示意图的完整几何与文字源代码，适用于课程18–21。作者为项目维护过程中使用的 Codex；制作过程保存在同一模块中，无外部图片、字体文件或应用截图输入，随项目 MIT 许可分发，不另要求署名。图片明确标注“课程主题示意图 · 非应用界面截图”。这不是对 `assets/seed/` 旧图补授权，旧图仍保持排除策略。

每份素材需补充作者/制作人、原始来源、明确许可或授权证明、制作/授权日期、适用版本、文件哈希、署名要求，以及是否允许修改和再分发。仅凭文件名、生成式风格或“网上找到”无法补齐这些记录。

有证据后再针对具体文件调整公开清单和 `.gitignore`，保留原许可与署名。自制素材保留源文件和生成/制作过程；截图去除身份信息、定位、支付码、消息和头像。外站教程继续用原站链接，不镜像原视频。
