## 复用工具

在项目根目录运行，要求 JDK17、Maven，以及已构建的后端类和 Spark 集群jar。工具直接读取现有本地数据源和YARN配置，不在脚本中保存密码。

```powershell
# 查看账号和课程总量，不打印个人记录或连接密码
./tools/recommendation-samples.ps1 -Mode inspect

# 事务内添加固定测试样本（本次已经完成；重复执行会跳过）
./tools/recommendation-samples.ps1 -Mode seed

# 导出新的独立模拟快照，输出 input=... 路径
./tools/recommendation-samples.ps1 -Mode export

# 针对指定模拟快照运行两个YARN任务，不写回线上分析表
./tools/recommendation-samples.ps1 -Mode run -InputDirectory 'spark-tmp/runs/fc303f44-f383-437b-9a7c-22b6c66c19da/in'
```

真实数据分析继续保持真实来源。若要消除真实批次的“样本不足”，仍需真实用户在后期首次学习未接触课程的记录；重复旧记录、增加模拟记录或降低门槛都不能提供这类真实证据。
