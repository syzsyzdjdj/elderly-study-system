# 智慧助老学习系统 - 后端接口文档

> 版本：v1.1（权限修正 + 接口补全）  
> 基础路径：`/api`  
> 技术栈：Spring Boot 3 + MyBatis-Plus + Spring Security + JWT

---

## 1. 基础约定

### 1.1 认证方式

所有需要登录的接口，请求头携带 JWT：

```
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

- Token 有效期：24 小时
- 无 Token 或 Token 失效 → HTTP 401
- 权限不足 → HTTP 403

### 1.2 统一返回结构

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数校验失败（msg 含具体字段错误） |
| 401 | 未登录或 Token 失效 |
| 403 | 权限不足 |
| 500 | 业务异常或系统错误（msg 含业务提示） |

### 1.3 角色权限

| 角色 | roleKey | 典型权限 |
|---|---|---|
| 超级管理员 | ADMIN | 全部接口 |
| 课程运营 | COURSE_MANAGER | 课程/分类/话术/分析/公告/奖品的增删改查（DELETE 仅 ADMIN） |
| 老年学员 | USER | 学习/收藏/积分/AI 陪伴/提醒/问答/语音合成 |

### 1.4 安全配置三层判定

接口能否访问，由三层规则依次判定：

1. **Spring Security URL 规则**（SecurityConfig）—— 最底层，放行少数公开接口，其余要求登录
2. **类级 @PreAuthorize** —— 整个控制器所有方法统一角色约束（覆盖 SecurityConfig 的 authenticated）
3. **方法级 @PreAuthorize** —— 单个方法细化角色约束（覆盖类级，未注解则继承类级）

本项目 URL 级放行：

| URL | 方法 | 说明 |
|---|---|---|
| `/api/login` | POST | 登录 |
| `/api/register` | POST | 注册 |
| `/uploads/**` | 任意 | 静态上传资源 |
| `/api/course/list` | GET | 课程列表 |
| `/api/course/{id}` | GET | 课程详情 |
| `/**` | OPTIONS | CORS 预检 |

**除以上外，其余接口一律要求登录**（`.anyRequest().authenticated()`），然后再由类级/方法级 @PreAuthorize 细化角色。

### 1.5 日期时间格式

- 时间戳：`yyyy-MM-dd'T'HH:mm:ss`（LocalDateTime，示例 `2026-10-23T14:30:00`）
- 仅日期：`yyyy-MM-dd`（LocalDate，示例 `2026-10-23`）
- 仅时间：`HH:mm:ss`（LocalTime，示例 `08:30:00`）

### 1.6 分页约定

分页参数统一为 `page`（默认 1）+ `size`（默认 10 或 20），返回 MyBatis-Plus 的 `Page` 结构：

```json
{
  "records": [],
  "total": 100,
  "size": 10,
  "current": 1,
  "pages": 10
}
```

## 3. 详细接口

### 3.1 认证鉴权

#### POST /api/login
**公开**

登录，返回 JWT + 用户信息。

请求体（JSON）：
```json
{
  "username": "admin",
  "password": "your-own-password"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | String | ✅ | 用户名 |
| password | String | ✅ | 密码 |

返回 data：
```json
{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "userInfo": { "id": 1, "username": "admin", "nickname": "管理员", "phone": "138xxxx", "avatar": "/uploads/images/xxx.png", "province": "福建", "city": "福州", "district": "" },
  "roleKey": "admin"
}
```

---

#### POST /api/register
**公开**

老人自助注册（默认 USER 角色）。

请求体（JSON）：
```json
{
  "username": "user001",
  "password": "abc123",
  "nickname": "老王",
  "phone": "13800000000",
  "province": "福建",
  "city": "福州",
  "district": "鼓楼区"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | String | ✅ | 用户名（唯一） |
| password | String | ✅ | 密码 |
| nickname | String | ❌ | 昵称，缺省取 username |
| phone | String | ❌ | 手机号 |
| province | String | ❌ | 常住省 |
| city | String | ❌ | 常住市 |
| district | String | ❌ | 常住区县 |

返回 data：`null`

---

#### POST /api/logout
**需登录**

退出登录（后端无状态，始终成功）。

返回 data：`null`

---

### 3.2 用户中心

#### GET /api/profile
**需登录（任意角色）**

获取当前登录用户资料（不含密码）。

返回 data：SysUser 对象，关键字段：
```json
{
  "id": 5,
  "username": "user001",
  "nickname": "老王",
  "phone": "13800000000",
  "avatar": "/uploads/images/xxx.png",
  "province": "福建",
  "city": "福州",
  "district": "鼓楼区",
  "fontSize": 3,
  "highContrast": 0,
  "voice": "elderly"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| fontSize | Integer | 字号偏好：1=小 2=中 3=大 |
| highContrast | Integer | 高对比度模式：0=关 1=开 |
| voice | String | TTS 音色偏好 |

---

#### PUT /api/profile
**需登录（任意角色）**

更新当前用户资料（可更新字段：nickname/phone/avatar/province/city/district/fontSize/highContrast/voice）。

请求体（JSON）：只需传要改的字段
```json
{
  "fontSize": 3,
  "voice": "elderly"
}
```

返回 data：更新后的 SysUser 对象

---

#### PUT /api/profile/password
**需登录（任意角色）**

修改密码。

请求体（JSON）：
```json
{
  "oldPassword": "abc123",
  "newPassword": "newpass456"
}
```

返回 data：`null`

**需登录（任意角色）**


---

#### POST /api/category/add
**权限：ADMIN / COURSE_MANAGER**

新增分类。

请求体（JSON）：
```json
{ "parentId": 1, "categoryName": "社保认证", "sort": 2 }
```

#### PUT /api/category/update
**权限：ADMIN / COURSE_MANAGER**

修改分类，请求体同 add，需带 id。

#### DELETE /api/category/{id}
**权限：ADMIN / COURSE_MANAGER**

删除分类（若该分类下有课程则禁止删除）。

**权限：ADMIN / COURSE_MANAGER**

返回 data：
```json
{ "matched": 18, "skipped": 3 }
```

### 3.4 课程

#### GET /api/course/list
**公开**

课程分页列表（带分类名；传 province/city 时按"全国通用 + 本地"分层过滤）。

查询参数：

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| page | long | ❌ | 1 | 页码 |
| size | long | ❌ | 10 | 每页条数 |
| categoryId | Long | ❌ | - | 分类ID（顶级分类会自动包含所有子分类） |
| keyword | String | ❌ | - | 标题/简介搜索 |
| status | Integer | ❌ | - | 状态：1=上架 0=下架 |
| province | String | ❌ | - | 按省过滤（返回全国通用 + 本省本地课） |
| city | String | ❌ | - | 按市过滤 |

返回 data：`Page<CourseInfo>`

---

```json
}
```

---

**权限：ADMIN / COURSE_MANAGER**

| 字段 | 类型 | 必填 | 说明 |

| province / city / district | String | ❌ | 本地课归属地；留空为全国通用 |

| pointsReward | Integer | 奖励积分 |
| status | Integer | 1=上架 |
| province / city / district | String | 本地课归属地；空=全国通用 |
| categoryName | String | 分类名（联表填充） |
| favorite | Boolean | 当前用户是否已收藏（未登录为 null） |
| recommendationReason | String | 推荐原因（仅推荐接口返回） |
