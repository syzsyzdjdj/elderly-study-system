# 演示与面试说明

## 快速浏览

界面导览 MP4（本地验收材料，不随公开源码分发） 由 2026-11-03 本地真实运行截图编排，无配音、无真实用户数据。它用于快速浏览界面，不是连续交互录屏，不证明语音、模型效果或生产性能。

截图环境：Java 17、MySQL 8.0.42 独立临时实例、Vue 开发服务。外部 AI 与 TTS 预热关闭；演示库将课程封面和视频地址置空，课程步骤截图使用代码绘制的示意图。数据库使用演示账号及迁移测试资料，没有导入真实业务库。后台未运行的分析保持空状态，不为展示伪造活跃量。完整界面截图见 `screenshots/`；可选用 Pillow、imageio-ffmpeg 和中文字体运行 `tools/make_ui_tour.py` 重建视频，应用运行不需要这些依赖。

## 五分钟现场演示

先按 [最小启动](quickstart.md) 准备自己的演示环境。

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0:00–0:40 | 注册并登录学习账号 | 业务对象与适老化设计；账号不是默认公共密码 |
| 0:40–1:40 | 打开课程、学习步骤和记录 | 文字/示意图可独立运行；大字号、行距和对比度设置 |
| 1:40–2:30 | 返回首页查看推荐来源 | 新用户补位、已学过滤、内容候选；不把补位称为模型效果 |
| 2:30–3:10 | 提问“怎么连 WiFi” | 关闭模型后返回本地来源，说明 FAQ / 模型 / 规则顺序 |
| 3:10–4:00 | 切换独立管理员账号查看后台 | 权限、课程维护、分析批次与人工审核 |
| 4:00–5:00 | 展示测试和模拟评估文档 | 举出一个失败边界、验证方法和未覆盖范围 |

语音演示需提前单独部署可用 TTS，现场确认资源后再演示分段播放、暂停/恢复与切换取消。没有 TTS 时说明依赖，不将静态音频冒充实时生成。

## 可讲的实现与追问

- 推荐：为何采用名次融合？如何避免已学课程重新补回？模拟模型如何与真实批次隔离？
- 语音：用户切换课程时旧请求回来怎么办？首段失败与预取失败有什么不同？缓存什么时候失效？
- 分析：一次批次的输入如何固定？任务运行成功与业务指标合格如何区分？
- 工程：应用账号为什么不能建表？首次管理员为何要显式创建？空库和已有库的迁移流程为什么不同？
