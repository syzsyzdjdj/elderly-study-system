## 当前数据的限制及后续验收

1. 旧生成器随机生成进度与完成状态，按日期排列后，有10,066条记录的进度低于此前同一用户课程的最高进度（同日记录仅按日期稳定排序，不能精确断言回退发生顺序）。这说明模拟过程与逐步学习不完全一致。当前统计使用新增分钟求和、完成状态取最大值，可计算，但不能据此论证真实学习轨迹。
2. 提问只有30种模板，576条记录、0个人工标签。接受分类的平均模型置信度约97.48%，并不代表97.48%的正确率。要验收分类，需要独立人工标注提问测试集、分类别指标和预先确定的合格阈值。
3. 推荐需要更多独立留出用户、不同时间段和真实用户样本；业务验收应先约定Recall/覆盖率/基线提升阈值。当前30个合成正样本只达到代码运行评估的最低要求。
4. 若目标是答辩展示“Spark完成统计、聚类、关联、推荐和问答分析流程”，当前数据能够支撑；若目标是证明上线推荐及地区需求识别有效，目前证据不足。
