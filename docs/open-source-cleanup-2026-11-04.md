# 开源内容修复记录

2026-11-04。本次修改本地源码和公开包策略，没有更新线上系统或轮换外部服务凭据。

## 已修复

- 移除后端固定重置口令以及前端新增账号、重置操作中的默认密码。管理员需明确设置新密码并二次确认；管理端密码至少12字符、UTF-8编码最多72字节，服务端和前端均校验。重置时拒绝原密码，数据库仅存 BCrypt 哈希。
- 重置 DTO 的密码字段只接受输入，不序列化到响应，也不出现在 DTO 的 toString 中；操作日志改为结构化递归脱敏，覆盖 newPassword、oldPassword、嵌套 API Key 和 Token，包括带转义符的值。
- 公开截图采用 docs/public-media.json 中8张演示图片的明确清单及 SHA-256。其余截图、教程画面、运维终端图和视频保留本地，公开包不包含；若清单图片被替换，扫描及打包失败，需要人工重新审核。
- 补齐12张官方教程图片的素材登记，记录来源证据仍不等于再分发授权；这些图片继续排除。NOTICE、素材说明和相关文档链接同步调整。
- 私钥、签名密码、演示账号文件、数据库文件、日志及归档增加排除规则。本地原材料未删除；真实部署文档与配置的修改前副本在被忽略的 work/open-source-fix/private-originals 中。
- Android 不再默认指向原服务器，缺少 appBaseUrl 会停止配置。构建参数要求 HTTPS 源站，拒绝 URL 中的密码、API 路径、查询和片段；CI 显式使用 example.invalid 作为编译占位，不访问实际服务。
- 联网验收脚本必须显式传 --base；公开部署文档的实际地址、实例与账号已改为明确标注的示例。安装脚本必须明确传入自己的公网 IP 和初始管理员名，不再使用原环境值。

## 行为和验证边界

重置接口现在要求 `{id,newPassword}`，旧的只传 id 的调用会被拒绝，因此后台前后端需一起更新。管理端编辑/新增密码采用相同强度校验；普通学员自行注册的既有策略保持原约定。

这次没有新增“强制首次改密”状态；后台会提醒管理员私下告知本人并提示修改。既有长期登录凭证因密码指纹变化而无法续签，已签发访问 JWT 仍按原到期策略处理，不宣称已实现立即全端踢出。
